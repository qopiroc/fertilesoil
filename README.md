# Fertile Soil — NeoForge 1.21.1

Требуется JDK 21. Сборка: `./gradlew build` (jar появится в `build/libs/`).
Запуск для теста: `./gradlew runClient`.

Если в проекте нет gradlew — скачайте официальный MDK
(https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle), скопируйте из него
gradlew, gradlew.bat и папку gradle/ сюда, либо просто перенесите папку src/
в MDK и поправьте mod_id в gradle.properties на fertilesoil.
